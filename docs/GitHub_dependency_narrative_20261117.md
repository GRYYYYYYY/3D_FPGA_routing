问题固定为：在给定架构和布局下，如何通过解除完整共享分支及阻塞网络的依赖，在明确时序和资源预算内释放冗余跨层占用。正文按问题、依赖洞察、统一设计和匹配验证组织，四段引言区分架构/布局、AIR/CRoute增量共享、已有跨层代价引导与本文的整组释放任务。既有共享、时序优化和跨层加权不是本文首创；当前也没有简单代价基线优越性或外部路由器复现主张。

方法将当前STA完整分支组选取、保留跨层共享域、失败网络放松、阻塞owner协调、整组接受与终结选点连接起来。机制图和三行归因表分别使用已核验的共享切口、robot释放消融和R1 owner对照。R1两臂同结果归于协调范围扩大；BNN九组没有释放事件，不能将其收益归给失败释放。

当前完整BNN结果在相同CPD下以1786线长换取39SB及2CB：SB减少47.56%，SB+CB总计数减少0.797%。N/D/D/N完整均时7308.61/9129.25秒，额外费用24.91%；原冷启动对照22.95%单独保留。最终两臂setup向量534改善/803退化、hold违例无增加。占用收益不等于芯片面积或功耗收益。

主表保留28个匹配行，原表另外14行完整移入补充材料，42行无遗漏。全部覆盖、无收益、初始失败、超时和基础设施错误仍有汇总与原始记录。六页编译和视觉检查通过，原投稿候选稿、paper19和当前确认规则不变。全文不依赖未来正向结果。
