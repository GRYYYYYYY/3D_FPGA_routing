垂直下界不约束 wire/CPD。若要保持当前算法行为，必须证明此时两个具体选择器没有可执行候选，并保留此前全部合法观测供独立终结选点。只证明“不可能再接受垂直资源改善”不足以一般性省略可能产生线长候选的搜索。证书必须针对当前物理输入、容量和计数口径，在完整计时中建立或明确计入复用成本；历史研究证明不能免费注入完整算法。
