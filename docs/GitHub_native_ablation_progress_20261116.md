# 原生组合验证、robot 无释放消融与六页正文

本次增量接续 `fc1a837`，公开证据基点仍为 `9734eee`。原有结果、队列和本地更新保留；研究继续进行。

统一方法仍是当前 STA 选组 → 跨层共享域 → 按网络失败释放 → 阻塞 owner 协调 → 整体合法候选接受 → 独立终结选点。本次完成两项预先登记的局部原生实验，没有新增独立电路或物理起点，也没有冻结完整确认版本。

| 已完成实验 | 实际结果 | 费用范围 |
|---|---|---|
| BNN 固定三网络组合 | FULL/STA、独立物理审计、输入封存和固定规则全部通过；2059607 wire / 82 SB / 5062 CB，CPD 13.228145690 ns | 单个导入候选验证 217.95 s，采样树 PSS 10.286 GiB；不是完整算法费用 |
| robot 关闭 failure-release | 同源、同23连接请求、权重、切口、原生二进制及 seed；首连接经9次尝试失败，事务完整回滚 | 导入事务 29.24 s；失败候选没有合法质量指标 |
| BNN 分组开发 | 16步后无适用切口并完成封存；2061345 wire / 43 SB / 5060 CB，CPD 13.607436067 ns | 完整导入流程 10308.49 s；不是冷启动完整配置 |

BNN 组合相对其合法源减少24线长，SB、CB和CPD不变；setup端点2改善、0退化，无新增hold违例。34个事前登记的连接延迟预测全部与原生结果精确匹配。它证明这个固定组合可实现，不能据此主张完整算法普遍受益，亦不能给它附上原7933.25秒完整流程费用。

robot 无释放消融仅改变失败释放开关。失败后源路由字节与完整端点向量精确恢复，未执行域释放。结合已完成的释放分支，它支持失败释放在这个事务中的操作性作用。原生搜索失败本身不是数学不可行证明；独立域／容量切口审计提供另一个有固定条件的解释。owner释放与重接仍是后续独立范围对照，不能把这里的结果归于owner协调。

BNN分组启发式相对历史K8控制同CPD、SB和CB，仅少32线长，完整导入流程时间却增加约45.20%。历史单次时间不是因果计时或统计加速证据；当前结果不支持将该启发式加入已登记dev03，后续重点继续放在跨输入与机制验证。四角色完整端点／实际工作量比较已挂接，在共享串行空位运行，不重复原生实验。
