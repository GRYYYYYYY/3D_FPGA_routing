## 原生 A0 到 A4 的实验状态

| 组别 | 实际含义 |
|---|---|
| A0 | 固定官方 VPR 的原生三维时序驱动路由器 |
| A1 | CHANZ 可配置拥塞成本乘 `1+w` |
| A2 | 可达且空间多样的跨层候选偏好 |
| A3 | 静态共享/拆分 DP，生成软引导 |
| A4 whole | 重规划后整网重布线 |
| A4 subtree | 重规划后保留合法分支，组合原生剪枝 |

原矩阵 769 次运行，637 次合法并通过独立限定范围审计，132 次失败保留；90 次串行计时均通过。20 电路筛查中 A0 和 A3 各成功 12/20；12 个共同成功用例的 A3 CPD 几何均值变化为 −1.39%，线长约 −0.01%，垂直占用约 −2.19%，其中 CPD 4 例改善、5 例不变、3 例变差。A4 没有稳定总体优势。不要把多次运行当成独立电路样本来宣称统计显著性。

DP 是本项目定义的候选表、层次划分和代理目标下的有限模型，不是 H3D 原论文算法逐行移植或全图 Steiner 最优解。当前规划限于两层、串行、clustered routing。架构混合了已发布硬块/平面模型和原生 CHANZ/scatter-gather；不是统一工艺校准的实体 FPGA。模型导线 R/C 为零，仍保留 fan-in 对应开关时延。

132 次失败的追加诊断完成，独立正式运行 457 次、成功 144 次并通过双重检查；另有 13 次成功的高强度辅助对照，统计分开：

| 原失败的后续状态 | 数量 |
|---|---:|
| 延长预算恢复 | 44，其中 16 次在 200 轮内，其余 28 次在 201–305 轮 |
| 固定输入存在独立容量不足证明 | 44 |
| 跑满 500 轮未收敛 | 33 |
| 两小时进程超时，未跑满 500 轮 | 11 |

独立宽度扫描共 38 个配置、13 个电路/布局实例：W100 成功 8/38，W120 为 20/38，W140 为 35/38，W160 为 38/38。关闭预测器、统一 200 轮；未观察到配对算法单侧成功。这不证明精确最小宽度，也不证明原 W100 一定无解。宽度改变可连带改变连接、扇入和时延。

证据在 `results/failure_diagnosis/report.html`、`analysis_native.json`、`validation_native.json`。四个代表性 DSP 出口容量证书为 conv_layer 64>44、dla_like.small 48>44、dla_like.medium 48>44、attention_layer 子集 28>22。原生失败不能用旧 LaZagna 布局 bug 统一解释。

## 已完成的论文时期 LaZagna 对照

独立目录 `results/lazagna_reproduction/` 已于 2026-10-23 完成：登记 126 条目，实际启动 114 次尝试，22 份合法路由全部通过 VPR FULL 与独立路径/开关/容量检查；107 个唯一文件重新核验摘要。23 项 Python 测试及提取后的 C++ 布局 guard 检查通过。详细执行脚本索引在 `implementation_manifest.json`。

固定参数为 100×100×2、W300、50% repeated-interval subset SB、延迟比例 0.739、cube_bb、seed1、inner_num0.5、route 时钟；3600 秒是包含图加载/lookahead/PnR 的进程时限。原仓库缺失配置引用的 `yosys.ys`，使用既有 Beyond Flatland BLIF，因此不宣称作者原网表或完整 RTL/bitstream 复现。

11 个严格原参数主运行：9 个 BRAM 时钟无路径、1 个 CLB 容量不足、1 个超时。理想时钟固定输入诊断在两套工具/图上各为 W100 成功 3/11、W300 成功 6/11；每个宽度各有一个上游容量不足而跳过的电路。这些计数不代表论文性能复现率。

架构核查的主要结论：

- W100/W300 两种全尺寸图中，全部 2548 个 DSP、188552 个 OPIN 的平面出口目标和容量逐项相同，没有发现原生迁移漏接 DSP 出口。内部 DSP W100 出口容量 44，每侧 22；边界另计。W300 内部为 130–132。
- 平面交换图不相同：内置 Wilton/fs=3 与 Beyond Flatland 自定义交换规则不同，跨版本即使同名规则也不保证 CHAN→IPIN 边相同。
- 旧图每方向用成对 CHANX/NONE，强制跨层，出口可接 L4/L16；当前原生双向 CHANZ 共享容量并可用于同层绕行，scatter/gather 仅接 L4。节点数不能直接当物理键合点数。
- 已检查图的实际平面→跨层→平面延迟：旧图接 L4 为 277.376 ps，接 L16 为 470.841 ps；原生接 L4 为 327.826 ps。137/142 ps 的单开关值不是整条路径延迟。
- 全尺寸 W100 图两族各有 344 个独立复核的 DSP 局部容量证书；证书重叠，缺口不可相加。证明只约束具体固定布局和需求。
- 发布架构 `spram.clk Fc=0` 与 route 时钟冲突，2352 个 BRAM 时钟 IPIN 无入边。dla_like.medium 需 23877 个 CLB，超过阵列 14308 个。这些不属于 H3D 搜索不收敛。
- 图生成时钟模式也是控制变量：旧图 route，原生沿用 A0 ideal。相同原生版本只将生成模式改为 route，可恢复 40×40×2 图的 2128 个 CLB 时钟引脚，并重排部分普通 CHAN→IPIN；DSP 出口及通道间边不变。BRAM Fc=0 仍存在。两次 native/bnn/route 使用 ideal 图的尝试已单列为模式冲突。
- 发布 XML 的 L4/L16 权重 280/40 在 W300 生成 262/38，与论文表 III 的 260/40 有差异。另生成字面表格敏感性图，未将其冒充原 XML 结果，也没有完整 PnR 性能比较。

旧版布局缺陷由 `af5b6a44340e69e4c2c9e44713626888a4b6bd5a` 引入：两处有效坐标判断被反向处理。隔离补丁在 `patches/lazagna-placement-validity-guards.patch`，独立程序在 `artifacts/bin/lazagna-guardfix/vpr`，没有覆盖原程序。三次匹配完整 PnR 控制均合法：

| 用例 | 原历史分支 | 仅修复两条 guard |
|---|---|---|
| bnn，route 时钟 | 超时 | 18 轮，12.2606 ns |
| conv_layer，ideal 时钟 | 12 轮，20.986 ns | 12 轮，9.34357 ns |
| dla_like.small，ideal 时钟 | 超时 | 15 轮，11.0514 ns |

退火温度点从原版 2 个变为约 99–106 个，交换中止率从约 93% 降到 1% 以下。该结果是所选旧分支的缺陷修复证据，不是 H3D 优势、论文错误证明或后续 LaZagna 的测量结果。配对检查见 `guardfix_input_equivalence.json`。
