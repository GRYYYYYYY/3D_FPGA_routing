# 测量与复现口径

本目录是独立的严格线程约束重执行。原始实验的结果和失败记录不被覆盖。A0、R1、B2 与 P1 使用单独构建的串行候选程序；它们分别来自固定的官方 VTR 开发提交、本项目修改、后续 LaZagna 移植分支与布局集成版本，不能称为对应发布版本的原封二进制。

本次复用已存在的打包普查和器件模型作为固定输入。这些上游输入产生时没有本目录的线程系统调用记录，因此即使后续各次布局与路由均满足线程约束，也不能把整个上游预处理称为严格单线程重现。所用架构是受控共同平面模型，理想时钟、资源预算与物理模型边界沿用登记协议。

训练和主要评估通过跟踪子进程的 `clone`/`clone3` 并结合进程树采样检查线程；跟踪会影响耗时及限时结果。训练选择仍按原登记规则执行，在合法数量和 CPD 相同时可能使用受跟踪影响的路由时间打破平局；这种选择是跟踪条件下的结果，不是未经干扰的速度测量。比较指标保留失败、超时和缺失结果，不能把样本筛选后的效果解释成所有电路的改善。

串行计时的候选方案使用继承式 seccomp 约束而不使用 ptrace。该过滤器禁止全部 `clone3`，并在 `clone` 请求创建线程时终止调用进程；它仍有内核过滤和进程监督开销，也可能改变原本使用 `clone3` 的程序路径。实际 A0、R1、B2 和 P1 工作负载必须通过独立对照和输入封存后，候选方案才可用于登记的串行计时；一个小电路的等价不能证明所有工作负载等价。共享主机的未隔离负载仍会影响计时。

原 P1 字面分区参数 0.03 与相对均分容量允许 3% 偏差的参数 1.5 分开记录。必须审计实际分区权重；不能因为布局或路由成功就称字面参数满足 3% 平衡。补充的固定布局 W100/W300 诊断是由已观察结果推动的后续实验，不能包装成对历史 20 电路结果的盲测复现。
